# 🔢 2048 · 霓虹版 NEON 2048

霓虹风格的单文件网页 2048，支持键盘与触屏操作。

## 🎮 玩法

- 方向键 / WASD / 滑动屏幕移动方块
- 相同数字合并翻倍，向 2048 进发
- Z 撤销一步 · R 重新开始
- 每步 +得分，最高分本地存档

## ✨ 特性

- 数字越高霓虹光效越强，2048 彩虹流动特效
- 新方块弹出动画 + Web Audio 合成音效
- 撤销功能（最多 30 步）
- 手机端虚拟方向键 + 触屏滑动
- 单文件自包含，零依赖
